# Foot Pain Identifier

MVP responsive in Next.js + TypeScript, ispirato al mockup fornito.

## Avvio

```bash
npm install
npm run dev
```

Apri `http://localhost:3000`.

## Funzioni

- selezione multipla delle aree dolorose
- due viste del piede
- intensità 0–10
- durata del dolore
- motore di regole locale
- risultati orientativi e disclaimer medico
- layout responsive e accessibile da tastiera

## Nota clinica

I testi e le regole sono dimostrativi. Prima della pubblicazione vanno verificati da un professionista sanitario e integrati con privacy policy, gestione del consenso e revisione legale.
